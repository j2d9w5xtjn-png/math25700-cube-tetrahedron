# Cube and Tetrahedron Rotations

Interactive rotations of the cube and the regular tetrahedron: the cube's 24 rotations permute its four long diagonals as S4, and the tetrahedron's 12 rotations permute its vertices as A4 (Math 25700, Lecture 3).

Live page: https://j2d9w5xtjn-png.github.io/math25700-cube-tetrahedron/

`index.html` is a built copy; the source and tests are kept elsewhere.
